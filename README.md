# Vortoria

**Play (no local server):** enable GitHub Pages, then open:

https://guestvrgt.github.io/vortoria/

## Pages setup
1. Repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / **/(root)** → Save

## Controls
- Click canvas → lock mouse
- Move mouse → look **360°** (yaw + pitch)
- **WASD** move · **Space** jump
- Avatar turns to face movement direction

Models load from CDN (`huh` repo). Your PlayFab/Photon IDs are on the Servers tab.
