## Full hub build
The complete multi-page Vortoria hub (Studio, Servers, clothing uploads, embedded play) is in `vortoria-site.zip` from the Grok session / your Google Drive.

```bash
unzip vortoria-site.zip
cd vortoria-site
python3 -m http.server 8080
```
