# Vortoria (website)

Public site for **Vortoria**.

**Full game client:** https://github.com/GuestVRGT/vortoria-client  
**Play:** https://guestvrgt.github.io/vortoria-client/ (enable Pages on the client repo)

This repo is the lightweight website. The playable hub (Studio, clothing, 360 camera, servers) lives in **vortoria-client** so it can be hosted on GitHub Pages without a local server.
